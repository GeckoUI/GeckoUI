# Drawer

A slide-out panel component that displays auxiliary content from any edge of the viewport. Provides a less intrusive alternative to modals for navigation menus, settings panels, filters, and contextual information with smooth transitions and flexible dismissal behaviors.

Supports both controlled JSX usage and an imperative `Drawer.show()` / `Drawer.dismiss()` API. Multiple imperative drawers can be stacked.

## Setup

The imperative API requires [`<GeckoUIProvider>`](/docs/gecko-ui-provider) to wrap your app.

```tsx
import { Drawer } from '@geckoui/geckoui';
```

## Basic Usage

<Preview>
  <BasicDrawerExample />
</Preview>

```tsx
import { useState } from 'react';
import { Drawer, Button } from '@geckoui/geckoui';

function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setOpen(true)}>Open Drawer</Button>
      <Drawer
        open={open}
        handleClose={() => setOpen(false)}
        placement="right"
        allowClickOutside
        className="w-80 p-6"
      >
        <h2 className="text-xl font-semibold mb-4">Drawer Content</h2>
        <p className="text-gray-600 mb-4">This drawer slides in from the right side.</p>
        <Button onClick={() => setOpen(false)}>Close</Button>
      </Drawer>
    </>
  );
}
```

## Props API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `false` | Control drawer visibility |
| `handleClose` | `() => void` | — | Callback when drawer should close |
| `placement` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'right'` | Edge from which drawer slides |
| `allowClickOutside` | `boolean` | `false` | Allow clicking backdrop to close |
| `dismissOnEscape` | `boolean` | `true` | Close drawer on Escape key press |
| `hideBackdrop` | `boolean` | `false` | Hide backdrop overlay (visual only) |
| `backdropClassName` | `string` | — | CSS class for backdrop |
| `className` | `string` | — | CSS class for drawer panel |
| `children` | `ReactNode` | — | Drawer content |

## Imperative API

`Drawer.show()` pushes a new drawer onto the overlay stack and returns an `id`. Call `Drawer.dismiss(id)` to close a specific drawer, or `Drawer.dismiss()` for the topmost.

```tsx
const id = Drawer.show(
  <QuickActionsMenu
    actions={globalActions}
    onActionClick={(action) => {
      handleAction(action);
      Drawer.dismiss(id);
    }}
  />,
  {
    placement: "bottom",
    className: "h-80 rounded-t-xl"
  }
);
```

### Stacking

```tsx
Drawer.show(<FirstPanel />, { placement: "right" });
// Later:
Drawer.show(<SecondPanel />, { placement: "right" }); // stacks on top
```

The topmost drawer captures Esc and click-outside events; lower drawers ignore them until they become topmost.

### Context consumption

```tsx
Drawer.show(<UserProfilePanel />, { placement: "right" });
// UserProfilePanel can call useContext(AuthContext) and get the real value
```

## Placement Options

- `"right"` — Slides in from the right (default)
- `"left"` — Slides in from the left
- `"top"` — Slides down from the top
- `"bottom"` — Slides up from the bottom

## Styling

**Backdrop** (`GeckoUIDrawer__backdrop`):
- `data-state="visible" | "hidden"` — Backdrop visibility
- `data-clickthrough` — Present when click-through is enabled

**Drawer panel** (`GeckoUIDrawer__drawer`):
- `data-placement="right" | "left" | "top" | "bottom"` — Slide direction
- `data-state="open" | "closed"` — Open/closed state

## Accessibility

- Keyboard navigation with Escape key support
- Click-outside detection
- ARIA `role="dialog"` applied
